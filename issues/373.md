### Feature Suggestion

Currently Jira Assistant can report only on issues where time is logged. But in some scenarios, it is required to run report on issuetype like initiative (which may be in different project) which may be sitting up in the issue hierarchy. Example: Story will be the issuetype where developers enter their timesheet, but management/stakeholder may want to run a consolidated report on initiative level where the hierarchy goes like this Initiative (project 1) -> Epic(project 2) -> Story(project 2).

As on today (11th November, 2024) we have to literally copy over all the time entries from the stories to its corresponding initiative  in order to run a cumulative time report.
